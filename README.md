# Car Dataset – My First Data Project

This is a practice dataset created using Microsoft Excel. **All the data used in this project is fictional and does not represent real company information or actual sales records.**

### What I Learned
- Exploring different features of Microsoft Excel.
- Creating and organizing a structured dataset.
- Entering and managing data.
- Using tables and formatting.
- Creating bar charts for data visualization.

### About the Dataset
- Company names and car models
- Car pricing
- Number of cars sold and unsold
- Repaired or damaged cars
- Customer service ratings

### Learning Outcome
This project helped me gain practical experience in data organization, Excel features and data visualization as part of my learning journey.
